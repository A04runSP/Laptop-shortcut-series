> A searchable keyboard-shortcut reference and lightweight practice tool, built for desktop and mobile browsers.

## 📖 About

Laptop Shortcut Series organizes Windows-oriented keyboard shortcuts, browser commands, Office workflows, coding tools, and laptop controls into nine categories. Entries explain what a shortcut does and when to use it. App-, version-, and hardware-dependent behavior should be treated as context-dependent rather than universal.

## ✨ Features

- Search across all categories by action, description, or key combination
- Desktop category buttons and a mobile category dropdown
- Previous / Next navigation plus left/right keyboard navigation
- **Practice mode:** flashcards and a multiple-choice quiz
- Local learning progress and best quiz score saved in the current browser using local storage
- Responsive layout with the black / cherry-red visual identity
- No installation or account required

**Progress is local to the browser and device.** It does not sync between phones and computers, and clearing browser data can remove it.

## 🔎 Accuracy and compatibility

Keyboard shortcuts can differ by operating system, app version, keyboard layout, device manufacturer, and user-customized keybindings. Some entries are workflows or commands rather than keyboard shortcuts; these are labeled as reference/compatibility material. Confirm important or unfamiliar shortcuts against the relevant official documentation.

Primary references for checking platform-specific behavior:

- [Microsoft Support — Windows keyboard shortcuts](https://support.microsoft.com/en-us/accessibility/windows/keyboard-shortcuts-in-windows)
- [Google Chrome Help — Chrome keyboard shortcuts](https://support.google.com/chrome/answer/157179?hl=en)
- [Microsoft Support — Keyboard shortcuts in Microsoft 365](https://support.microsoft.com/en-us/topic/keyboard-shortcuts-in-microsoft-365)
- [Visual Studio Code — Keyboard shortcuts and keybindings](https://code.visualstudio.com/docs/configure/keybindings)

These references are starting points for ongoing review, not a claim that every entry in the catalog has been independently verified against every OS/app version. Mobile layouts have been checked by fetching the deployed page at a mobile viewport; actual physical-device interaction testing is still required.
